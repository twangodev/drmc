# Fonts

Self-hosted variable fonts, unchanged from the local `sdocx/web` reference assets:

- [Overused Grotesk](https://github.com/RandomMaerks/Overused-Grotesk):
  `OverusedGrotesk-VF.woff2`, SIL Open Font License 1.1; see
  `OverusedGrotesk-LICENSE.txt`.
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono):
  `JetBrainsMono-VF.woff2`, SIL Open Font License 1.1; see
  `JetBrainsMono-OFL.txt`.

These assets retain their original font licenses. DRMC's application code uses
Apache 2.0.
